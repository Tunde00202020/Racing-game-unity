# Racing Game - Unity 6

A 3D racing game built with Unity 6 LTS featuring real car physics, 
professional race track, AI competitors and full racing HUD.

## Gameplay Features
- Real car physics using Unity WheelCollider system
- Professional oval race track (Cartoon Race Track by RCC Design)
- Checkered start/finish line
- Minimap showing full track with player position
- Speed HUD (km/h), Lap counter, Race timer, Position tracker
- Nitro boost system
- AI competitor cars
- Race Manager tracking race positions
- Speed-based camera FOV

## Controls
| Key | Action |
|-----|--------|
| W / Up Arrow | Accelerate |
| S / Down Arrow | Reverse |
| A / Left Arrow | Steer Left |
| D / Right Arrow | Steer Right |
| Space | Brake |
| Left Shift | Nitro Boost |

## Requirements
- Unity 6.3 LTS
- Universal Render Pipeline (URP)
- Free assets required from Unity Asset Store:
  - [Cartoon Race Track Oval](https://assetstore.unity.com) by RCC Design
  - [Kenney Car Kit](https://kenney.nl/assets/car-kit)

## Built With
- Unity 6.3 LTS
- C# scripting
- Unity WheelCollider physics
- Universal Render Pipeline (URP)
- Covers Open 3D Engine (O3DE) and Stride engine brackets
